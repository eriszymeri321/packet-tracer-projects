# Computer Networks - Cisco Packet Tracer Project

## 📝 Overview
This repository contains a complete network topology created in Cisco Packet Tracer as part of the Computer Networks course work.

## 🛠️ Features & Configuration
- **Network Topology Design**: Structured local network infrastructure connecting routers, switches, and end devices.
- **IP Addressing & Subnetting**: Allocation and logical segmentation of network resources.
- **Routing & Switching**: Configured device-to-device communication and traffic routing.
- **Connectivity Testing**: Verified end-to-end network connectivity across nodes.

## 🚀 How to Run
1. Download and install **Cisco Packet Tracer**.
2. Download or clone this repository.
3. Open `ProjektiRRjetatkompjuterike.pkt` directly in Cisco Packet Tracer.
